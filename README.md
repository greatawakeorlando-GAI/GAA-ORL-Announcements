# GAI Announcements

A small installable web app (PWA) for sending announcements to the
congregation, with push notifications so people get a pop-up alert on their
phone when something new is posted -- without needing an app store listing.

**What it does**

- A public page (`/`) lists current announcements. Anyone can open it, and
  it can be "installed" to a phone's home screen like a normal app.
- A staff page (`/admin`), protected by a single shared password, is where
  someone posts a new announcement. Posting it also sends a push
  notification to every phone that's turned on alerts.
- Notifications work through the browser's built-in Push API -- no separate
  push notification service or paid SDK required.

**How it's built** -- Next.js (one app, handles both the pages and the
small API behind them), Upstash Redis for storing announcements and
notification subscriptions (generous free tier, no server to manage), and
the `web-push` library for sending the actual push messages.

---

## 1. Before you deploy

You'll need two free accounts:

1. **[Vercel](https://vercel.com)** -- hosts the app. Free tier is plenty
   for a single congregation.
2. **[Upstash](https://console.upstash.com)** -- stores announcements and
   subscriptions. Create a Redis database (any region close to you), then
   open it and copy the **REST URL** and **REST TOKEN** shown on its
   details page. You'll paste these into Vercel in step 3.

You'll also generate a set of "VAPID keys" -- these are what let your
server prove to Apple/Google's push services that notifications are coming
from you. Generate your own (don't reuse anyone else's):

```
npm install
npm run generate-vapid-keys
```

This prints a **Public Key** and a **Private Key**. Keep the private one
secret -- treat it like a password.

## 2. Choose an admin password

This is the one password staff will use to sign in at `/admin` and post
announcements. There are no separate staff accounts -- keep it simple, but
don't use anything guessable, and plan to rotate it occasionally the same
way you would a shared door code.

## 3. Deploy to Vercel

**Option A -- from GitHub (recommended):**

1. Push this folder to a new GitHub repository.
2. In Vercel, "Add New Project" -> import that repository.
3. Before the first deploy, open **Environment Variables** and add:

   | Name | Value |
   |---|---|
   | `UPSTASH_REDIS_REST_URL` | from Upstash |
   | `UPSTASH_REDIS_REST_TOKEN` | from Upstash |
   | `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | from step 1 |
   | `VAPID_PRIVATE_KEY` | from step 1 |
   | `VAPID_SUBJECT` | `mailto:` + an email you monitor |
   | `ADMIN_PASSWORD` | from step 2 |
   | `NEXT_PUBLIC_CHURCH_NAME` | e.g. `Great Awakening International` |

4. Deploy. Vercel gives you a URL like `gai-announcements.vercel.app`
   (you can later attach your own domain, e.g. `announcements.yourchurch.org`,
   for free in Vercel's Domains settings).

**Option B -- straight from your computer, no GitHub:**

```
npm install -g vercel
cd gai-announcements
vercel
```

Follow the prompts, then add the same environment variables under
**Project Settings -> Environment Variables** in the Vercel dashboard and
redeploy (`vercel --prod`).

## 4. Try it

- Open the deployed URL on your own phone.
- **On Android/Chrome:** tap "Turn on announcement alerts" -- you can get
  push notifications right away, installing to the home screen is optional
  (though still nice to have).
- **On iPhone:** Safari only allows notifications for apps added to the
  Home Screen, not for a regular browser tab. Tap the Share icon -> **Add
  to Home Screen**, then open the app from that new icon (not from Safari)
  and turn on alerts from there. The app will remind people to do this if
  they haven't yet.
- Go to `/admin`, sign in with the admin password, and post a test
  announcement. Everyone currently subscribed should get a notification
  within a few seconds, and it'll appear in the feed on `/`.

## Customizing it

- **Branding/colors:** edit the CSS variables at the top of
  `app/globals.css` (`--brand` is the main color used in the header and
  buttons).
- **Church name:** set `NEXT_PUBLIC_CHURCH_NAME` in your environment
  variables -- no code change needed.
- **Icon:** `public/icons/` has a placeholder bell icon generated by
  `scripts/make_icons.py`. Replace those PNG files with your own logo at
  the same filenames/sizes (192x192, 512x512, plus maskable versions and a
  180x180 Apple touch icon) and it'll show up as the app icon everywhere.

## Local development

```
npm install
cp .env.example .env.local   # fill in your own values
npm run dev
```

## Good to know / limitations

- **One shared admin password**, not individual staff logins. Fine for a
  small communications team; if GAI later wants per-person accounts and an
  audit trail of who posted what, that's a bigger change worth doing
  separately (e.g. adding real authentication) rather than something to
  bolt on casually.
- **iOS requires the "Add to Home Screen" step** before push notifications
  work at all -- that's an Apple restriction on all web apps, not something
  specific to this build.
- **Free tiers**: Vercel and Upstash's free tiers comfortably cover a
  congregation under a few thousand people for this kind of light usage. If
  GAI grows a lot, you'd simply upgrade the Upstash plan -- no code changes
  needed.
